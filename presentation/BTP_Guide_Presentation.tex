\begin{frame}{1. Problem: Prefetch Interference in Shared LLCs}
  \vspace{-0.12cm}
  \begin{columns}[t, onlytextwidth]
    \begin{column}{0.485\textwidth}
      \begin{tcolorbox}[tealpanel]
        {\footnotesize\textbf{\color{Obsidian}Regular / Stride Co-Runners (\texttt{gcc}, \texttt{perlbench})}}\par\vspace{0.08cm}
        \begin{itemize}\setlength{\itemsep}{0.22em}\scriptsize
          \item \textbf{Memory Locality:} Sequential array strides and compact L1/L2 working sets (\texttt{IPC} $\approx 1.83\text{--}2.07$).
          \item \textbf{Prefetch Utility:} Hardware L2 stride/AMPM prefetchers mask 200+ cycle off-chip DRAM miss stalls.
          \item \textbf{Sensitivity:} Sensitive to displacement when sharing an 8\,MB LLC with streaming or irregular neighbors.
        \end{itemize}
      \end{tcolorbox}
    \end{column}%
    \hfill%
    \begin{column}{0.485\textwidth}
      \begin{tcolorbox}[archpanel]
        {\footnotesize\textbf{\color{Obsidian}Irregular Co-Runners (\texttt{mcf}, \texttt{omnetpp})}}\par\vspace{0.08cm}
        \begin{itemize}\setlength{\itemsep}{0.22em}\scriptsize
          \item \textbf{Memory Locality:} Linked pointer chasing and irregular heap traversals (\texttt{IPC} $\approx 0.08\text{--}0.34$).
          \item \textbf{Prefetch Accuracy:} On \texttt{mcf x 4}, decoupled L2 accuracy is $29\text{--}32\%$; $\sim 68\text{--}71\%$ of prefetches receive no L2 reuse (mix-1 is aggregated across 4 cores).
          \item \textbf{Set Churn:} High volume of unreferenced prefetch fills circulates through shared LLC ways.
        \end{itemize}
      \end{tcolorbox}
    \end{column}
  \end{columns}

  \vspace{0.22cm}
  \begin{tcolorbox}[summarystrip]
    {\footnotesize\textbf{\color{NavyPrimary}Hypothesized Cause --- Prefetch-Oblivious Replacement:}}\par\vspace{0.06cm}
    \scriptsize
    Standard policies (\texttt{LRU}, \texttt{SRRIP}) ignore \texttt{access\_type} on LLC fills and insert speculative blocks at high or intermediate priority (MRU or $RRPV=2$). We hypothesize that this displaces active working sets of co-runners (e.g., \texttt{omnetpp} drops from \texttt{0.2895} under LRU to \texttt{0.2770} under SRRIP), though per-core eviction attribution was not logged directly and \texttt{PA-LRU} tracks \texttt{LRU} closely.
  \end{tcolorbox}
\end{frame}

            \texttt{PA-SRRIP} is functionally \textbf{\texttt{PACMan-M}} (Wu et al., MICRO'11: distant prefetch insertion, standard hit promotion). Our contribution is the matched multicore evaluation, storage audit, and adaptive controller diagnosis.

            \texttt{PACMan-Dyn} uses 32-set Set Dueling (\texttt{PSEL}); \texttt{PA-Adaptive} tests one global 6-bit $+3/-1$ counter.
          \item \textbf{1-Bit/Line Hardware Cost:}\\
            Reading \texttt{is\_prefetched} costs \textbf{16\,KB} ($8\times$ \texttt{SHiP}) standalone, so \texttt{0.75\,B} overhead holds only if reusing a PMU bit.
        \end{itemize}
      \end{tcolorbox}
    \end{column}
  \end{columns}
\end{frame}

        \begin{enumerate}\setlength{\itemsep}{0.12em}\scriptsize
          \item \textbf{L2-to-LLC Usefulness Hinting:}\\
            Forward L2 \texttt{pf\_useful} feedback down to \texttt{PA-Adaptive} so symmetric \texttt{mcf x 4} stays in $RRPV=2$ instead of collapsing toward $RRPV=3$.
          \item \textbf{Evaluate \texttt{PACMan-Dyn}:}\\
            Implement per-set Set Dueling (\texttt{PSEL}) to combine \texttt{DRRIP}'s \texttt{0.7367} strength on thrashing streams with wire-level filtering.

            Run 50M--100M SimPoints across 4+ mixes alongside lightweight PC filtering for demand lines.
        \end{enumerate}
      \end{tcolorbox}

    \begin{column}{0.485\textwidth}
